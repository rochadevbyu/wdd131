Referências e Créditos

Contexto do Projeto

Este site acadêmico foi desenvolvido para apresentar as funcionalidades do SGINF-RPPS. O sistema descrito não é fictício; trata-se de uma solução tecnológica real e operacional, utilizada ativamente na gestão previdenciária. O conteúdo reflete desafios e soluções autênticos vivenciados na administração pública.

Autoria de Textos e Conteúdo

Toda a estruturação lógica, arquitetura de informações e redação base do conteúdo foram criadas pelo autor do projeto, Roberto Ferreira da Rocha. O modelo de inteligência artificial Gemini (Google) foi utilizado como ferramenta de apoio editorial exclusivo para o refinamento de vocabulário.

Geração de Imagens

As imagens ilustrativas que simulam as interfaces e dashboards do sistema foram geradas artificialmente por meio de prompts de texto utilizando a inteligência artificial ChatGPT (OpenAI), visando fins puramente acadêmicos e de representação visual do software, uma vez que foram utilizadas imagens reais como referências para criação das imagens.
